Every tappable thing in the app and where it goes. The build follows this exactly.

Seven rules

  1. The bottom nav always reaches the five main screens. The current one is orange.
  2. Any player name or player card opens that player's profile.
  3. → moves deeper inside the app. ↗ leaves it, to the FPL site in a new tab.
  4. The depth switch never leaves the page. It opens layers in place.
  5. Pages without the nav (story, profile, archive) have a back link top left, to where you came from.
  6. One orange primary action per screen.
  7. Nothing that looks tappable does nothing.

The three ways to go deeper

On a story: depth switch, Headline → The read → Data room teaser, in place.

Into the evidence: the teaser's link opens that story's evidence in the data room.

Into a player: any name opens the profile, from anywhere.
