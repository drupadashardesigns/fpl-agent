# StatTile

A number with a plain-words label, used four at a time in the orange header.

- Number in `stat` (display face, tabular figures), label in `label` below it.
- On the header: `orange-soft` fill, `ink` number, `orange-soft-ink` label. On ground: `surface` fill, `ink-subtle` label.
- Always a 2 by 2 grid on a phone, gap `space-2`, `radius-md`.
- Labels say what the number means ("to the top 10k"), not a code ("GAP").
