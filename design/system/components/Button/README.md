# Button

One orange primary button per screen; everything else is secondary.

- **Primary**: `orange` fill, `on-orange` text, `button` type style, 50px tall, `radius-md`. The label says exactly what happens ("Try it in the planner", "Make these transfers").
- **Secondary**: transparent, 2px outline (`chart-muted` on light, `navy-line` on navy), text in `ink` or `on-navy`.
- Side by side: primary takes the remaining width, secondary hugs its label. Gap `space-2`.
- Never white text on orange. Never two orange buttons in one view.
