# TransferRow

One recommended transfer: who goes out, who comes in.

- Two equal columns with Out and In labels (`label`, `on-navy-muted`) above names (`player`). The outgoing name is weight 500, the incoming 700.
- The arrow is the → character in `accent-on-navy`, hidden from screen readers; the Out and In labels carry the meaning.
- Inside the call card: `navy-raised` fill, `radius-md`, padding `space-3` by 14px, rows `10px` apart.
- In the planner the same row sits on `surface` with `ink` text and a remove button.
