# BottomNav

The app's five places: Edition, Squad, Planner, Ask, Alerts.

- A floating `ink` bar, `radius-xl`, 12px from the screen edges and bottom (plus the safe-area inset), padding 6px.
- The current tab is an `orange` pill with `on-orange` text in `label-strong` and `aria-current="page"`; others are `on-navy-muted` in `label`.
- Text labels only until an icon set exists. 50px tall targets.
- Alerts may carry a count in a small `orange-tint` pill when something needs action before the next price update.
