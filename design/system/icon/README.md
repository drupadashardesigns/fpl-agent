# App icon: Floodlight

The home-screen icon for the AlooSoul app, chosen 3 Nov 2026.

- `aloosoul-icon.svg`: source, 512 x 512 viewBox.
- `aloosoul-icon-512.png`: export used for the Android home-screen shortcut.

Orange ground (`orange`), navy floodlight (`ink`), light panel and beam in the orange tints. Artwork sits inside the middle two-thirds so Android's round or rounded-square masks don't crop it.

The app runs inside claude.ai, which doesn't let a page set its own home-screen icon. On Drupad's Android phone the icon is applied through a Shortcut Maker website shortcut that opens the app's artifact link. If the app ever moves to its own hosting (for example GitHub Pages), use these files for the web app manifest and apple-touch-icon.
